# 統計解析スケジュール管理

試験ごとのスケジュールを、Google スプレッドシートのタイムライン表示（ガントチャート）で管理するためのツールです。
試験一覧に試験名と開始日を入れると、タイムラインにバーが表示されます。終了日を入れなければ、開始日から4か月分のバーになります。

シートの構成・初回設定・注意点・開発者向けの情報は [詳細](DETAILS.md) を参照してください。

## 使い方

### 試験を登録する

試験一覧シートに試験名・開始日を入力します。終了日は任意です。

- 試験名は試験情報マスタのプロトコルIDから選べます。マスタにない名前も入力できます（警告表示のみ）。
  - セルに文字を入力すると、入力した文字に一致するプロトコルIDが候補として表示されるので、そこから選べます。
- 終了日を入力すると、タイムラインのバーはその日までになります。空欄なら開始日の4か月後までです。
- 開始日が空欄の場合は、今日の日付に1日だけのバーが表示されます（日付が決まっていないが予定がある試験を忘れないため）。
  - タイムラインでは試験名の後ろに「（スケジュール未定）」が付きます。
  - 試験一覧では開始日のセルが黄色になります。日付が決まったら入力してください。

### 試験を非表示にする

表示状態を「非表示」にすると、その試験はタイムラインに表示されなくなります。試験一覧の開始日・終了日はそのまま残ります。

### バーの色を変える

試験名を入力すると、試験名のセルに淡い色が自動で付き、その色がタイムラインのバーの色になります。
試験名のセルの背景色を手動で変えると、バーの色も変わります。
