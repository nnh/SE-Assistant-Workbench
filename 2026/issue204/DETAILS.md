# 統計解析スケジュール管理 詳細

使い方は [README](README.md) を参照してください。このページには、シートの構成・初回設定・注意点・開発者向けの情報をまとめています。

## シート構成

| シート | 内容 | 入力 |
|---|---|---|
| README | README へのリンク | 自動作成 |
| 試験情報マスタ | 研究管理システムから取り込んだ試験情報（プロトコルID、試験名、研究種別、状態、FPI、LPO、登録開始、登録終了、中間用データ固定、追跡終了） | 自動取り込み（編集不可） |
| 試験一覧 | 試験名、表示状態、開始日、終了日、表示名、タイムライン開始、タイムライン終了（タイムライン表示の元データ） | 試験名〜終了日は手入力、表示名〜タイムライン終了は数式で自動計算。タイムライン開始・終了の列は非表示 |

## 初回設定

1. Apps Script エディタの「プロジェクトの設定 → スクリプト プロパティ」で、スクリプトプロパティ `RESEARCH_SYSTEM_URL` に研究管理システムのURLを設定してください。
   - 未設定のまま「初期設定」を実行すると、ダミー値が登録され、設定を促すメッセージが表示されます。
2. スプレッドシートを開き直し、メニュー「初期設定 → 初期設定を実行」を実行します（初回は Google の承認画面が表示されます）。
3. 試験情報マスタの A1 セルに「アクセスを許可」が表示されたらクリックします（初回のみ）。
4. タイムライン表示を作成します。
   1. 試験一覧シートの A:G 列を選択し（F・G 列は非表示ですが範囲に含めます）、「挿入 → タイムライン」を実行します。
   2. タイムラインの設定を次のようにします。

      | 設定 | 列 |
      |---|---|
      | カードのタイトル | 表示名 |
      | 開始日 | タイムライン開始 |
      | 終了日 | タイムライン終了 |
      | カードの色 | 試験名 |

## 仕組み

- 試験一覧の表示名・タイムライン開始・タイムライン終了は、2行目に入れた数式（ARRAYFORMULA）で計算しています。
  - 表示名 = 試験名（開始日が空欄なら後ろに「（スケジュール未定）」を付ける）
  - タイムライン開始 = 開始日（空欄なら今日（TODAY 関数））
  - タイムライン終了 = 終了日（空欄なら開始日の4か月後（カレンダー上、EDATE 関数）。開始日も空欄なら今日）
  - 試験名が空欄、または表示状態が「非表示」の行は、タイムライン開始・終了が空欄になり、タイムラインに表示されません。
- 開始日・終了日は手入力なので、非表示にしても値はそのまま残ります。
- 終了日は任意入力です。空欄のときの扱いが分かるよう、見出しを「終了日（空欄なら開始日+4か月）」にし、セルを選んだときに説明（入力規則のヘルプテキスト）が表示されるようにしています。
- 試験名があり、表示状態が「非表示」でなく、開始日が空欄のとき、開始日のセルが条件付き書式で黄色になります。
- 試験名を入力すると、編集時のスクリプト（onEdit）が、まだ色が付いていない試験名のセルに淡い色を付けます。タイムラインの「カードの色」に試験名の列を指定しているため、この色がバーの色になります。

## 制限事項・注意点

- 表示名〜タイムライン終了の列は数式で計算しているため、直接入力しないでください。編集しようとすると警告が表示されるよう、「初期設定」で範囲の保護（警告のみ）をかけています。
- 「初期設定」を再実行すると、試験一覧のヘッダーと表示名〜タイムライン終了の数式を設定し直し、タイムライン開始・終了の列を非表示にします（試験名・表示状態・開始日・終了日と背景色はそのまま残ります）。
- 試験情報マスタでは、研究管理システムの状態が Completed・Stop・No Support の試験は取り込みません。

## 開発

[ASIDE](https://github.com/google/aside)（TypeScript + clasp）で構成しています。

| ディレクトリ・ファイル | 内容 |
|---|---|
| `src/index.ts` | エントリポイント（onOpen、onEdit、メニューから呼ぶ関数） |
| `src/constants.ts` | シート名・列・色などの定数 |
| `src/schedule-logic.ts` | 試験名のセルに付ける色の選択（GAS API に依存しない） |
| `src/formula-builder.ts` | 試験情報マスタ・試験一覧に書き込む数式の組み立て |
| `src/sheet-service.ts` | スプレッドシートの読み書き |
| `test/` | Jest のテスト |

```bash
npm install
npx clasp login
npm test
npm run deploy
```

- `npm run deploy` は lint・テスト・ビルドのあと、`.clasp-dev.json` のスクリプトにプッシュします。本番環境へは `npm run deploy:prod`（`.clasp-prod.json`）でプッシュします。
- `.clasp-dev.json`・`.clasp-prod.json` は Git 管理対象外です。
